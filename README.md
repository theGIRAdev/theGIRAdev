## 🧭 Обо мне

Пишу бэкенд на Java: модель данных, репозитории, сервисный слой и REST-контроллеры.
Довожу проект до состояния, когда он поднимается одной командой, а ключевые сценарии
покрыты тестами — интеграционными через `TestRestTemplate` и изолированными через
`@WebMvcTest` + MockMvc.

- 🎯 **Фокус:** Spring Boot, Spring Data JPA, PostgreSQL
- 🧪 **Тестирование:** JUnit 5, Mockito, MockMvc, `@MockBean`
- 🌱 **Изучаю:** Hibernate, миграции схемы, интеграционные тесты
- 🐍 **Параллельно:** Python и 1С
- 🤝 **Открыт** к стажировке/junior-позиции и фидбеку по коду

## ⚙️ Как я работаю

- сначала модель данных и сценарии, потом контроллеры;
- на каждый ключевой сценарий — тест, включая негативные кейсы;
- проект должен подниматься одной командой, а README — объяснять запуск без догадок;
- коммиты и структура — по одной понятной причине на изменение.

---

> Проект готов не тогда, когда он компилируется, а тогда, когда на его запросы приходят правильные ответы — и это подтверждено тестами.
