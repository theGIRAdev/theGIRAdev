## 🧭 Обо мне

Пишу бэкенд на Java: от модели данных и репозиториев до REST-контроллеров. Довожу проект до состояния, когда он поднимается одной кнопкой, а каждый эндпоинт покрыт тестом — интеграционным через `TestRestTemplate` или изолированным через `@WebMvcTest`.

- 🎯 **Фокус:** Spring Boot, Spring Data JPA, PostgreSQL
- 🧪 **Тестирование:** JUnit 5, MockMvc, Mockito, `@MockBean`
- 🌱 **Изучаю:** Hibernate, миграции схемы, интеграционные тесты
- 🐍 **Параллельно:** Python и 1С
- 🤝 **Открыт** к фидбеку по коду и учебным проектам
